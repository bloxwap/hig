## Native simulator/emulator verification · 2026-10-14

Delivery: [#53](https://github.com/bloxwap/hig/pull/53). Evidence: `evidence/native-sim/` (`native-sim.json`, per-platform result JSON, hierarchy dumps and downscaled captures). Environment: iOS Simulator (iPhone 16 Pro, iOS 26.5, Xcode 27.2) and Android emulator (Medium_Phone_API_35, Android 15 arm64 Google Play image) running Release builds of the packed candidate 0.1.0-candidate.sha1172b6a3. Harness: `scripts/native-sim/` (packed-candidate app build, XCUITest on the iOS Simulator, UiAutomation instrumentation, uiautomator, TalkBack keyboard flow and GestureSheet runs on the Android emulator). The earlier Linux VM could not boot simulators; these observations replace that execution blocker but are still simulator/emulator observations.

Defects found by running the native gallery and fixed with tests: hoisted Expo SDK 57 `expo-asset`/`expo-constants` crashed launch (`Cannot find native module 'ExpoAsset'`); Button split adjacent label text into gapped fragments; Switch (47x27dp) and Slider (18dp) exposed sub-48dp accessibility targets; iOS VoiceOver increment/decrement never reached the community slider; HIGProvider forced LTR under an Arabic OS locale; TalkBack ignored overlay focus requests (now `viewHoverEnter` on Android) and Menu/Select did not return focus to their trigger; Search/InstallCommand rendered empty live-region elements; native code text used the body face and RTL direction; the optional GestureSheet never presented on first open (Gorhom DISMISSING state); the gallery lacked host keyboard avoidance for Android 15 edge-to-edge.

Simulator/emulator observations do not cover: physical Display-P3 panels, tactile haptics (the Simulator has no Taptic Engine; the emulator has no motor, only VibratorManager history), audible speaker output/latency/silent switch/interruptions, VoiceOver (unavailable in the iOS Simulator), TalkBack speech and touch exploration on physical hardware, or physical touch/gesture feel. Those remain physical-hardware-only residuals in the table rows above and in `planning/issue-coverage.json` (`nativeSimulator.physicalHardwareOnly`).
