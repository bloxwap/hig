Implements separate React DOM and React Native renderers for actions, surfaces, fields, selection, overlays, navigation, status and financial displays, with host-owned product/docs/marketing recipes. Individual exports keep base controls independent from optional chart/audio/native backends. DOM overlays reuse scoped Radix behavior; native uses Modal and explicit platform alternatives.

Base: `hig/m1-foundations`. Head: `hig/m2-components`. Suggested title: **M2: React and native components, chart boundary and product recipes**.
