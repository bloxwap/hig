# Contributing

Run `npm ci && npm run check`, SSR smoke, and the Expo bundle before review. Update source and generated artifacts together. Keep examples out of runtime packages. Explain intent, state, accessibility, platform mapping, migration and evidence. Record owner and expiry for exceptions. Never claim a mock or simulator proves physical sound/haptics.

Cite HIG 0.1.0 with a commit permalink. Do not copy entire component folders. Incrementally adopt versioned packages and per-component imports. PRs must identify unperformed checks, upstream gaps and rollout/rollback. Publication remains disabled for this candidate.
